| Failure mode | Guarantee | Test files (re-run by this command) | Hand-written evidence of a real run (not re-run) |
|---|---|---|---|
| A stale price is paid | An authorization belongs to one quote version (a SHA-256 over canonical JSON); a changed quote cannot reuse it. | `tests/quote/canonical.test.ts`, `tests/quote/gate.test.ts`, `tests/db/quote-accept.test.ts`, `tests/db/payments-checkout.test.ts` | `doc/evidence/payments-real-sandbox.md` |
| A customer is charged twice | A repeated or racing merchant decision, capture or webhook produces no second charge and no second preparation job. | `tests/db/payments-decide.test.ts`, `tests/db/payments-webhook.test.ts`, `tests/db/payments-reconcile.test.ts`, `tests/payments/request-id-classify.test.ts`, `tests/db/fulfillment-create.test.ts` | `doc/evidence/payments-real-sandbox.md`, `doc/evidence/fulfillment-real-sandbox.md` |
| Stock that is not there is sold | Stock is reserved under a row lock in one database call; a configuration is validated against live stock; timers never release stock while a PayPal operation may be in flight. | `tests/db/reservation-reserve.test.ts`, `tests/db/reservation-guards.test.ts`, `tests/db/reservation-sweep.test.ts`, `tests/reservation/invariant.test.ts`, `tests/catalog/validate-stock-budget.test.ts` | none yet |
| The model touches the money | Model output cannot set a price, quantity, status or state; strict schemas reject extra fields; every configuration shown was validated and priced by code. | `tests/intake/tools.test.ts`, `tests/intake/extraction.test.ts`, `tests/intake/eval-scenarios.test.ts`, `tests/db/intake-injection.test.ts` | `doc/evidence/ai-intake-real-model.md` |
| The wrong person sees an order | Access is enforced on the server for every query: customer links are checked, shop pages see only the signed-in owner's rows. | `tests/db/rls.test.ts`, `tests/db/inquiry-reads.test.ts`, `tests/merchant-access.test.ts`, `tests/customer-link.test.ts` | none yet |

## What this command does not re-run

The real PayPal sandbox runs, the real-model runs and the hosted runs are recorded by hand in `doc/evidence/` when each was done, after an explicit yes. They are not re-run by this command and their results are not repeated here. Mocked, replayed and scripted tests are labeled as such in their own files. Everything in this project is sandbox-only and uses synthetic data.
